# Logos

Drop logo files here with exactly these names. If a file is missing, the page shows the name as text instead, so nothing breaks.

| File | Shows as | Caption |
| --- | --- | --- |
| `mlh.svg` | MLH | Partner |
| `cybersecurity-society.png` | Cybersecurity Society, University of Galway | Host |
| `liberty-it.svg` | Liberty IT | Exclusive industry sponsor |

The page background is dark (`#14060e`), so use light or white versions of each logo. Logos are shown up to 40px tall. To change names or file types, edit `LOGOS` in `lib/event.ts`.
